THE QUICK GUIDE

A few words. A fresh cut.

AutoCut edits existing footage on your device. It uses a free, rule-based instruction parser, not a paid AI service.

  1. Pick a short video. Start with a clip under 100 MB on a phone. Larger files need more memory.
  2. Describe supported edits. Combine instructions with commas or new lines. Check the edit plan before processing.
  3. Make the cut, then export. Keep the tab in the foreground. Preview the result and tap Export to save.

Supported instructions

Good to know

Aspect changes center-crop the image. “Lower the audio volume” means 50%. Fades last up to 1 second. MP4 keeps audio when available; MP3 exports only audio edits, trim, and speed. It needs a source audio track.

The ~31 MB FFmpeg engine needs an initial internet download. AutoCut caches the app and engine for later offline use when storage permits. No external CDNs, accounts, or uploads.

Install on Android

Open this site in Chrome. Tap ⋮ → Add to Home screen → Install. If Install is unavailable, you can still use AutoCut in the browser. Offline storage can be removed by Android when space is low.
